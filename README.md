# Repo Graveyard

Every repo dies. Some deserve a eulogy.

Sign in with GitHub and Repo Graveyard turns your abandoned repositories into headstones, each with a cause of death, an epitaph and an obituary. Filter the graveyard by language and by how long a repo has been dead, sort it, and open any grave for its vital signs.

Right now it runs on sample data in `src/data/sampleRepos.json`. GitHub OAuth is next.

## Development

```sh
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Built with React and Vite.
